## 一、项目总体定位

面向赛事交付的智慧病房云边端协同系统。复用智能教室已验证的 Vue + FastAPI + MQTT + MySQL + SQLite + Docker Compose 技术路线，领域模型、数据契约、事件闭环、边缘推理与协同训练面向病房安全监护重新设计。

- 范围：1 病房（W-01）× 3 床（B01~B03）
- 事件：13 类安全事件（跌倒/坠床/抽搐/离床/夜间徘徊/长时间静止/压疮/异常体态/设备故障/门区异常/环境异常/护士呼叫/交接班）
- 服务：8 个 Docker Compose 服务（mqtt-broker / mysql / cloud-backend / training-coordinator / cloud-frontend / cloud-llm-service / diffusion-service / 3×edge）
- 代码规模：约 2.9 万行 + 文档约 1.2 万行；Git 共 68 提交，4 人协作
- 里程碑：最终提交 8/31 23:59
