### 7.1.2 多源融合设计原则

每项功能都不是单传感器判定，遵循"多源交叉降低误报"原则：

| 融合模式 | 示例 | 价值 |
|---|---|---|
| 摄像头 + 床垫 | 跌倒 = posture=falling + fall_score + 床位离床 | 单摄像头误判翻身，床垫交叉确认 |
| 摄像头 + 门磁 | 门区离开 = 门磁开 + 摄像头有人 | 单门磁无法判断是否有人离开 |
| 床垫 + 摄像头 bbox | 离床双源校验 | 床垫误报时摄像头交叉验证 |
| 跨帧 + 关键点 | 抽搐 = 关键点帧间抖动方差 | 单帧无法检测抽搐 |
| 时间 + 床垫 | 夜间徘徊 = 夜间时段 + 离床持续 | 区分日间正常离床 |

## 7.2 跌倒检测实现

### 7.2.1 规则定义

```python
# 规则1：跌倒疑似（P1）
if cam and inference:
    fall_score = inference.predictions.get("fall_score", 0)
    posture = inference.predictions.get("posture", "unknown")
    if posture == "falling" and fall_score > 0.5:
        if self._should_fire("fall_suspected"):
            events.append(SafetyEvent(
                event_type="fall_suspected",
                priority="P1",
                confidence=fall_score,
                rule_hits=["posture=falling", f"fall_score={fall_score:.2f}>0.5"],
            ))
```

### 7.2.2 多源确认逻辑

跌倒判定需同时满足两个条件，降低误报：
1. **摄像头**：`posture=falling` 且 `fall_score>0.5`（YOLOv8-pose 关键点几何判定）
2. **床垫**：`occupied=False`（确认人已离开床面，非床上翻身）

单摄像头可能误判（如患者弯腰捡东西），床垫交叉确认"人确实不在床上"。

### 7.2.3 fall_score 计算

YOLOv8-pose 原生不输出 fall_score，由关键点几何特征加权计算：

```python
fall_score = 0.5 * horizon_level   # 躯干水平度：shoulder_y 与 hip_y 差越小越高
           + 0.3 * low_position     # 重心高度：bbox 中心越低越高
           + 0.2 * keypoint_conf    # 关键点置信度均值
```

## 7.3 坠床预警实现

### 7.3.1 规则定义

```python
# 规则6：坠床预警（P1）- 事前预警
if cam and bed:
    posture = cam.data.get("posture", "unknown")
    fall_score = cam.data.get("fall_score", 0)
    occupied = bed.data.get("occupied", False)
    if posture == "lying_edge" and occupied and fall_score >= self.BED_EDGE_FALL_SCORE:
        if self._should_fire("fall_prediction"):
            events.append(SafetyEvent(
                event_type="fall_prediction",
                priority="P1",
                rule_hits=["posture=lying_edge", f"fall_score>={self.BED_EDGE_FALL_SCORE}", "bed_occupied"],
            ))
```

### 7.3.2 事前预警 vs 事后检测

| 维度 | fall_prediction（坠床预警） | fall_suspected（疑似跌倒） |
|---|---|---|
| 时机 | 事前（还在床上，已到边缘） | 事后（已跌倒） |
| posture | lying_edge（床沿） | falling（跌倒中） |
| 床位 | occupied=True（还在床上） | occupied=False（已离床） |
| 价值 | 提前干预，避免跌倒发生 | 跌倒后快速响应 |

坠床预警是本项目的核心创新点之一：通过 `lying_edge` 姿态（躯干重心偏移到 bbox 边缘）在跌倒发生前预警，护士可提前干预。

### 7.4.1 规则定义

```python
                priority="P1",
                confidence=tremor_score,
                rule_hits=[f"tremor_score={tremor_score:.2f}>={self.TREMOR_THRESHOLD}"],
            ))
```

### 7.4.2 tremor_score 跨帧计算

抽搐检测依赖**跨帧关键点抖动**，单帧无法判定。`TremorDetector` 保留最近 10 帧关键点，计算腕/肘/膝关键点的帧间位移方差：

```python
class TremorDetector:
    def update(self, keypoints):
        self.history.append(keypoints)
        if len(self.history) < 3:
            return 0.0
        # 计算腕/肘/膝关键点（9,10,7,8,13,14）的帧间位移方差
        displacements = []
        for i in [9, 10, 7, 8, 13, 14]:
            xs = [f[i][0] for f in self.history]
            ys = [f[i][1] for f in self.history]
            displacements.append(np.std(xs) + np.std(ys))
        return min(1.0, sum(displacements) / len(displacements) / 0.05)
```

癫痫发作时关键点高频抖动，tremor_score 超过 0.6 阈值即触发告警。

## 7.5 离床与夜间徘徊实现

### 7.5.1 离床规则（双源校验）

```python
# 规则2：离床（P2）- 床垫主导 + 摄像头辅助
if bed:
    absence_sec = bed.data.get("absence_seconds", 0)
    occupied = bed.data.get("occupied", True)
    if not occupied and absence_sec >= self.BED_LEAVE_THRESHOLD:
        # 摄像头 bbox 床区多边形交叉验证
        bed_leave_conf = 0.85
        if cam and self.BED_REGION_POLYGON:
            bbox = cam.data.get("bbox")
            cx, cy = bbox[0] + bbox[2]/2, bbox[1] + bbox[3]/2
            in_bed = point_in_polygon((cx, cy), self.BED_REGION_POLYGON)
            if not in_bed:
                bed_leave_conf = 0.92  # 双源一致
            else:
                bed_leave_conf = 0.50  # 床垫误报
```

**置信度加权策略**：

| 场景 | 床垫 | 摄像头 bbox | 置信度 | 说明 |
|---|---|---|---|---|
| 双源一致 | 离床 | 中心在床区外 | 0.92 | 高置信，确认知床 |
| 床垫误报 | 离床 | 中心在床区内 | 0.50 | 存疑，可能传感器故障 |
| 未校验 | 离床 | 无 bbox/无多边形 | 0.85 | 向后兼容 |

### 7.5.2 夜间徘徊升级

### 7.6.2 异常体态（规则8）

```python
if cam:
    posture = cam.data.get("posture", "unknown")
    if posture in self.ABNORMAL_POSTURE_TYPES:  # curled/leaning/grabbing_chest
```

异常体态由 YOLOv8-pose 17 关键点几何判定：

| posture | 几何特征 | 可能急症 |
|---|---|---|
| curled | 肩-髋-膝三段夹角都小（蜷缩） | 腹痛 |
| leaning | 肩 x 偏移大于髋 x（前倾） | 呼吸困难 |
| grabbing_chest | 腕关键点落在肩-髋矩形内（抓胸） | 心脏不适 |

## 7.7 压疮预防实现

```python
# 规则10：压疮预防（P3）- 同一体位持续≥2小时
if cam:
    posture = cam.data.get("posture", "unknown")
    position_duration = cam.data.get("position_duration", 0)
    if position_duration >= self.BEDSORE_DURATION and posture not in ("unknown", "standing"):
        events.append(SafetyEvent(
            event_type="bedsore_risk",
            priority="P3",
            rule_hits=[f"posture={posture} unchanged", f"duration>={self.BEDSORE_DURATION}s"],
        ))
```

与长时间静止（5 分钟）的区别：压疮预防阈值更长（2 小时 = 7200 秒），且排除"站立"姿态（站立不需翻身）。提醒护士协助翻身，降低压疮发生率。

## 7.10 设备故障实现

```python
# 规则11：设备故障（P3）- 传感器质量 degraded 持续≥60秒
any_degraded = any(o.quality.degraded for o in observations)
if any_degraded:
    if self._degraded_since is None:
        self._degraded_since = now
else:
    self._degraded_since = None
if self._degraded_since and (now - self._degraded_since).total_seconds() >= self.DEVICE_FAULT_DEGRADED_SECONDS:
    degraded_sources = [o.source_type for o in observations if o.quality.degraded]
    events.append(SafetyEvent(event_type="device_fault", priority="P3", ...))
```

跨周期跟踪降级持续时间，避免瞬时抖动误报。降级原因包括：摄像头遮挡/低照度、床垫传感器故障、环境传感器断连。
