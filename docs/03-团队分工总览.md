## 关键依赖关系

```
亚伦（模型选型 + 框架）──-> 景彬（场景脚本 + 前端）
                      │
                      ├──-> 建鸿/振鑫（训练调度）
                      │
                      └──-> 烽亮/先伟（扩散模型 + 数据集）
                                   │
                                   └──-> 彦晗（云边协同）
```

**关键路径提醒**：
1. 亚伦的模型选型是景彬场景脚本和彦晗云边协同的前提
2. 建鸿的赛事材料方向影响全员交付
3. 振鑫的 FedAvg 实现是先伟测试与数据回流的前提
4. 烽亮的扩散模型产物是先伟数据集扩充的输入
