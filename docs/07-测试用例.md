# 测试用例文档

> 智慧病房云边协同系统 - 测试用例
> 本文档定义单元测试清单、功能测试用例、断网自治测试、性能指标与已发现并修复的 bug 记录。
> 对齐 edge/docs/04-测试用例.md 模板，按病房场景重新设计测试覆盖。

## 1. 测试概述

### 1.1 测试目标

验证智慧病房云边协同系统的功能完整性、性能指标和边缘自治能力：

- 13 类安全事件正确识别与上报
- 10 项智能功能全部落地
- 事件状态机正确流转（new -> notified -> acknowledged -> resolved/false_positive/escalated）
- 告警时延 ≤ 2 秒（P1 紧急事件）
- 断网情况下边缘节点仍可本地告警
- 恢复网络后缓存事件自动补传
- 8 服务 Docker Compose 一键启动稳定运行

### 1.2 测试环境

- 操作系统：Windows 11 / Linux
- 容器：Docker Desktop（含 docker compose）
- 浏览器：Chrome / Edge 最新版
- Python：3.11（边缘与云端）
- Node.js：18+（前端构建）
- 硬件（演示阶段）：Orange Pi 5（RK3588 NPU）+ USB 摄像头 + ESP32 床垫传感器
- 模拟数据：场景驱动器 `edge-agent/src/scenario.py` 提供 4 阶段状态机

### 1.3 测试范围

| 范围 | 说明 |
|------|------|
| 边缘侧决策逻辑 | 13 类事件识别、融合引擎、推理输出字段 |
| 云端 API 接口 | 21 路由全部覆盖 |
| 前端护士站 | 床位卡片、告警工作台、交接班面板 |
| 端到端集成 | 边缘 -> MQTT -> 云端 -> WS -> 前端 |
| 通信可靠性 | MQTT QoS 1、断网补传、幂等去重 |
| 断网自治能力 | 边缘节点断网后仍可本地告警 |
| 协同训练链路 | training-coordinator 调度器骨架 |
| 性能指标 | 告警时延、推理耗时、并发、稳定性 |

### 1.4 测试执行命令


### 2.3 v0.4.0+ 新增回归测试

当前实际执行结果为 `edge-agent` 78 项、`training-coordinator` 15 项、`cloud-backend` 56 项、`cloud-llm-service` 9 项；均使用标准库 `unittest` 发现并通过（云端 LLM 服务以 pytest 运行，因模块导入路径差异）。

- `test_fusion.py`：行为摘要、活动透传、离床双源校验（多边形交叉验证）、护士呼叫透传。

### Bug-001 事件去重窗口导致同类型事件漏报

| 项目 | 内容 |
|------|------|
| 发现时间 | 2026-07-20 |
| 严重级别 | 高 |

| 修复 | `edge-agent/src/fusion.py` 去重键改为 `bed_id + event_type + details 关键字段`，fall_suspected 与 fall_prediction 视为不同事件 |
| 验证 | `test_dedupe` 通过；手动注入两事件间隔 5 秒，均正常上报 |
| 状态 | 已修复 |

### Bug-002 交接班班次时区错位

| 项目 | 内容 |
|------|------|
| 发现时间 | 2026-07-21 |
| 严重级别 | 中 |
| 现象 | 调用 /api/shift-summaries/generate 生成夜班摘要，查询到的是前一天的事件 |
| 根因 | `main.py` 中班次时段按本地时区（+08:00）计算，但查询 `occurred_at` 时未将本地时间转 UTC，导致时段偏移 8 小时 |
| 修复 | `cloud-backend/app/main.py:429-442` 增加 local_tz = +08:00，`local_start.astimezone(utc)` 后再查询 |
| 验证 | 夜班（00:00-08:00 本地）生成摘要，event_count 与实际事件数一致 |
| 状态 | 已修复 |

```python
    assert "total" in r.json()
    print("PASS: TC-104 查询事件列表")

    # 需先有 P1 事件

        r = requests.post(f"{BASE}/api/events/{event_id}/ack",
                          json={"action": "acknowledge",

                                "operator_name": "演示护士",
```
