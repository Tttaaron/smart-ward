# 智慧病房事件字典

> 本文档定义智慧病房系统中所有安全事件的类型、优先级、状态机与字段规范。
> 是前后端、边缘端联调的**事件层唯一标准**，与 `contracts/safety_event.json` 对齐。

## 1. 事件类型（event_type）

| event_type | 中文名 | 优先级 | 默认来源 | 说明 |
|---|---|---|---|---|
| `fall_suspected` | 疑似跌倒 | P1 | 边缘端 | 摄像头姿态=falling + fall_score>0.5 + 床位离床 |
| `nurse_call` | 护士呼叫 | P1 | 前端/按钮 | 护士呼叫按钮触发，边缘端可透传 |
| `bed_leave` | 离床 | P2 | 边缘端 | 床位 absence_seconds ≥ 阈值（默认 30s） |
| `infusion_anomaly` | 输液异常 | P2 | 边缘端 | 滴速异常/低液位/输液完成/中断 |
| `door_departure` | 门区异常离开 | P2 | 边缘端 | 门磁 open + 摄像头检测到人离开区域 |
| `night_wandering` | 夜间徘徊 | P2 | 边缘端 | 夜间时段（22:00-06:00）+ 持续离床 |
| `environment_anomaly` | 环境异常 | P3 | 边缘端 | 温度/CO₂/光照超阈值 |
| `node_offline` | 节点失联 | P3 | 云端 | 边缘节点健康心跳超时 |
| `fall_prediction` | 坠床预警 | P1 | 边缘端 | 床位占床 + 姿态=lying_edge + fall_score 超阈值（事前预警） |
| `long_still` | 长时间静止 | P2 | 边缘端 | 同一体位持续超阈值（默认 5 分钟），可能是昏迷/不适 |
| `abnormal_posture` | 异常体态 | P2 | 边缘端 | posture 命中 curled/leaning/grabbing_chest，可能是急症早期信号 |
| `seizure` | 抽搐检测 | P1 | 边缘端 | tremor_score 超阈值，可能是癫痫发作 |
| `bedsore_risk` | 压疮预防 | P3 | 边缘端 | 同一体位持续超阈值（默认 2 小时），提醒翻身 |
| `device_fault` | 设备故障 | P3 | 边缘端 | 传感器 quality.degraded 持续超阈值（默认 60 秒） |

## 2. 优先级（priority）

| 优先级 | 含义 | 处置要求 |
|---|---|---|
| **P1** | 紧急 | 前端置顶闪烁，要求护士立即确认；边缘端不等待云端即本地告警 |
| **P2** | 高优先级 | 在规定时限内确认（建议 5 分钟） |
| **P3** | 提醒 | 进入待办队列，可批量处理 |

## 3. 事件状态机（state）

```text
                ┌─────────────┐
                │     new     │  边缘端新生成
                └──────┬──────┘
                       │ 云端收到并入库
                       ▼
                ┌─────────────┐
                │   notified  │  已推送到护士站
                └──────┬──────┘
                       │ 护士点击"到场"
                       ▼
                ┌─────────────┐
     ┌──────────│ acknowledged│  已确认（开始处置）
     │           └──────┬──────┘
     │                  │
     │     ┌────────────┼────────────┐
     │     ▼            ▼            ▼
     │ ┌───────┐  ┌──────────┐  ┌───────────┐
     │ │resolved│  │false_    │  │escalated  │
     │ │       │  │positive  │  │           │
     │ │已处置 │  │误报      │  │升级       │
     │ └───────┘  └──────────┘  └───────────┘
     │
     └─ 从 acknowledged 也可直接 resolve/false_positive/escalate
```

### 状态转换规则

| 当前态 | 允许的 action | 目标态 |
|---|---|---|
| `new` | （云端自动） | `notified` |
| `notified` | acknowledge | `acknowledged` |
| `notified` | resolve | `resolved` |
| `notified` | false_positive | `false_positive` |
| `notified` | escalate | `escalated` |
| `acknowledged` | resolve | `resolved` |
| `acknowledged` | false_positive | `false_positive` |
| `acknowledged` | escalate | `escalated` |
| `resolved` / `false_positive` / `escalated` | （终态） | - |

## 4. 事件字段（对齐 contracts/safety_event.json）

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `event_id` | uuid | 是 | 事件唯一 ID（边缘端 UUID4 生成） |
| `ward_id` | string | 是 | 病区 ID |
| `node_id` | string | 是 | 边缘节点 ID |
| `bed_id` | string | 是 | 床位 ID |
| `event_type` | enum | 是 | 见 §1 |
| `priority` | enum | 是 | P1/P2/P3 |
| `state` | enum | 是 | 见 §3 |
| `occurred_at` | iso8601 | 是 | 事件发生时间（UTC） |
| `detected_at` | iso8601 | 是 | 边缘端检测到的时间 |
| `confidence` | float | 是 | 置信度 0~1 |
| `model.model_name` | string | 是 | 模型名（如 yolo-nano-pose / rule-fusion-v1） |
| `model.model_version` | string | 是 | 语义化版本（如 1.0.0-int8） |
| `model.inference_ms` | int | 是 | 推理耗时毫秒 |
| `evidence_refs` | array | 是 | 证据引用（脱敏截图/片段指针），可空数组 |
| `rule_hits` | array | 否 | 命中的规则列表 |
| `details` | object | 否 | 事件特有补充字段 |

## 5. 处置记录（event_dispositions）

每次确认/处置/升级操作生成一条处置记录，含：

| 字段 | 说明 |
|---|---|
| `action` | acknowledge / resolve / false_positive / escalate |
| `operator_id` | 操作者 ID（演示阶段用别名） |
| `operator_name` | 显示名（演示别名，不存真实姓名） |
| `operator_role` | nurse / charge_nurse / admin / observer |
| `result` | 处置结果（resolve 时必填） |
| `note` | 备注 |
| `occurred_at` | 操作时间 |

## 6. 边界与约束

1. **人工复核闭环**：所有事件输出均为"疑似事件/辅助提示"，不自动执行任何临床处置。
2. **隐私脱敏**：默认仅上传事件摘要、脱敏截图或裁剪片段；原始视频留边缘端。
3. **误报回流**：`false_positive` 标记作为训练数据回流前必须脱敏与人工审核。
4. **幂等**：`event_id` 全局唯一，云端按此去重；断网补传不产生重复告警。
