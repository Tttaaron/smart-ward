|------|-----|

| 模型 | Qwen/Qwen2.5-14B-Instruct-GPTQ-Int4（~9.3GB 显存） |
| 服务端口 | **8501**（vLLM OpenAI 兼容 API） |

## 二、启动命令

```bash
HF_ENDPOINT=https://hf-mirror.com \
/root/miniconda3/bin/vllm serve Qwen/Qwen2.5-14B-Instruct-GPTQ-Int4 \
  --host 0.0.0.0 --port 8501 --max-model-len 2048
```

启动耗时：模型加载约 9 秒，API 就绪约 10-20 秒。

## 四、先伟接入说明（cloud-llm-service）

1. **切换真实模式**：`LLM_MODE=vllm`
2. **端点配置**：`VLLM_ENDPOINT=http://localhost:8501/v1/chat/completions`
3. **模型名**：`Qwen/Qwen2.5-14B-Instruct-GPTQ-Int4`
4. 代码已在 `cloud-llm-service/app/llm_client.py` 适配（vLLM chat API 格式）

启动 cloud-llm-service（vLLM 模式）：
```bash
cd /root/autodl-tmp/cloud-llm-service
LLM_MODE=vllm VLLM_ENDPOINT=http://localhost:8501/v1/chat/completions \
  /root/miniconda3/bin/python -m uvicorn app.main:app --port 8004
```

## 五、注意事项

1. **重启后需重新启动 vLLM**（AutoDL 实例关机后进程不保留，模型文件在 `/root/autodl-tmp/huggingface-cache/` 保留）
2. **显存共存**：扩散模型（SD 1.5）与 14B 同时跑需要 ~13GB，4090 24GB 可以共存，但建议错开
3. **网络**：国内镜像 `hf-mirror.com` 已配置，无需额外设置
4. **演示前预热**：正式演示前先发一次请求避免首 token 慢
