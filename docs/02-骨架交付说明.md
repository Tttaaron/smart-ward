## 4. 启动与验收

### 4.1 一键启动

```powershell
cd smart-ward
Copy-Item .env.example .env   # Windows
docker compose up --build
```

启动后：
- 护士站工作台：http://localhost:8081
- 云端 API 文档：http://localhost:8001/docs
- 协同训练 API：http://localhost:8002/docs
- MQTT：`localhost:1884`

### 4.2 本地测试

```powershell
# 边缘代理测试（10 项）
cd edge-agent
python -m pytest tests/ -v

# 协同训练测试（4 项）
cd ../training-coordinator
python -m pytest tests/ -v
```

### 4.3 端到端验收清单

- [ ] `docker compose up --build` 拉起 7 服务无崩溃
- [ ] 3 个 edge-agent 启动后发送 observation + health
- [ ] `GET /api/wards` 返回 W-01 + 3 床 + 节点状态
- [ ] `GET /api/stats` 返回在线节点数
- [ ] 手动注入事件触发跌倒场景，护士站收到 P1 告警
- [ ] 点击"到场"/"处置"，事件状态更新并广播
- [ ] 断开某 edge-agent 网络，事件本地缓存；恢复后补传

### 4.4 手动注入事件测试

