4. **⚠ 前端"比赛展示保护"会让按钮看似无反应**：边端长时间运行后事件数超 200，
   前端自动切到演示数据模式（点击生成只重设同一份演示数据）。**所有页面 URL 加
   `?live=1` 即绕过保护使用真实数据**（如 `http://localhost:8081/shifts?live=1`）。
   现场验证/取证一律带 `?live=1`
5. 云端存储已切换为 SQLite（零依赖），历史 MySQL 数据不自动迁移；边端病人档案
