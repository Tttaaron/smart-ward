## 10.2 云端部署

### 10.2.1 一键启动

```powershell
# 1. 获取代码
git clone <repository-url>
cd smart-ward

# 2. 配置环境变量
Copy-Item .env.example .env   # Windows
# cp .env.example .env          # Linux/macOS

# 3. 一键启动 8 服务
docker compose up --build
```

### 10.2.2 端口映射表

| 服务 | 容器端口 | 主机端口 | 访问地址 | 说明 |
|---|---|---|---|---|
| mqtt-broker | 1883 | 1884 | localhost:1884 | MQTT 通信 |
| mysql | 3306 | 3308 | localhost:3308 | 数据库（root/smartward_root） |
| cloud-backend | 8000 | 8001 | localhost:8001/docs | API 文档 |
| training-coordinator | 8000 | 8002 | localhost:8002/docs | 训练 API |
| cloud-frontend | 80 | 8081 | localhost:8081 | 护士站 |
| edge-bed-01/02/03 | - | - | - | 边缘代理（无外部端口） |

### 10.2.4 3 床场景编排

`docker-compose.yml` 为 3 个边缘代理配置不同场景，演示完整事件闭环：

| 床位 | SCENARIO_PROFILE | 演示侧重 |
|---|---|---|
| B01 | fall,nurse_call,fall_prediction,seizure | P1 紧急救护 |

## 10.3 端侧部署

### 10.3.1 Orange Pi 5 烧录

```
1. 下载 Ubuntu 22.04 LTS (aarch64) 镜像
2. 用 balenaEtcher 烧录到 64GB SD 卡（U3 A2 级）
3. 首次启动配置：SSH + Wi-Fi + 时区（Asia/Shanghai）
4. 安装 Docker：
   curl -fsSL https://get.docker.com | sh
   sudo usermod -aG docker $USER
5. 启用 Docker（开机自启）：
   sudo systemctl enable docker
```

### 10.3.2 摄像头接入

```python
# CameraAdapter 真实接入时替换 read()

class CameraAdapter(BaseAdapter):

        self.cap.set(cv2.CAP_PROP_FRAME_WIDTH, 1920)
        self.cap.set(cv2.CAP_PROP_FRAME_HEIGHT, 1080)

    def read(self) -> Observation:
        ret, frame = self.cap.read()
        # frame 传给 inference.run() 做 YOLO 推理
        ...
```

### 10.3.3 床垫传感器接入

ESP32 + FSR402 压力传感器通过 Wi-Fi MQTT 上报：

```
ESP32 -> Wi-Fi -> MQTT Broker -> edge-agent 订阅
```

真实接入时 `BedSensorAdapter.read()` 替换为订阅 ESP32 的 MQTT 主题。

### 10.3.4 YOLOv8n-pose 模型部署

```
1. 模型转换：
   .pt -> .onnx（ultralytics export）
   .onnx -> .rknn（rknn-toolkit2，INT8 量化，校准集 100-200 张）

2. 部署到 Orange Pi 5：
   /app/models/yolov8n-pose-1.0.0-int8.rknn（~6MB）

3. 灰度下发：
   POST /api/models/deploy -> MQTT model/deploy -> inference.load_model()
```

## 10.5 常见问题排查

### 10.5.1 容器起不来

| 现象 | 原因 | 解决 |
|---|---|---|
| mysql 启动失败 | 端口 3308 被占用 | `netstat -ano | findstr 3308` 查占用并释放 |
| cloud-backend 启动失败 | 等待 MySQL 健康检查 | healthcheck 会重试 20 次，耐心等待 |
| edge-agent 连不上 MQTT | mqtt-broker 未就绪 | edge-agent 有重连机制，5 秒重试 |
| 前端空白页 | nginx 代理后端未启动 | 先确认 `localhost:8001/health` 可访问 |

### 10.5.2 MQTT 连不上

```bash
# 检查 broker 状态
docker compose ps mqtt-broker
docker compose logs mqtt-broker

# 测试连接

```

## 10.6 生产环境建议

### 10.6.1 安全加固

| 项 | 演示阶段 | 生产建议 |
|---|---|---|
| MQTT 认证 | allow_anonymous true | 账号密码 + ACL（按 topic 限制读写） |
| MQTT 加密 | 无 TLS | TLS 1.2+ 传输加密 |
| 前端鉴权 | 无 | JWT + 角色权限（nurse/charge_nurse/admin/observer） |
| 数据库密码 | 环境变量明文 | vault 密钥管理 |
| CORS | allow_origins=["*"] | 限定具体域名 |

### 10.6.2 性能优化

| 维度 | 演示阶段 | 生产建议 |
|---|---|---|
| MySQL | 单实例 | 主从复制 + 读写分离 |
| MQTT | 单 broker | 集群 + 共享订阅 |
| 后端 | 单实例 | 多实例 + 负载均衡 |
| 观测表 | 单表 | 按月分表（数据量大时） |
| 边缘缓存 | SQLite 单文件 | 定期归档 + 清理 |

### 10.6.3 高可用

| 组件 | 演示阶段 | 生产建议 |
|---|---|---|
| 云端后端 | 单实例 | 多实例 + 健康检查 + 自动重启 |
| MQTT Broker | 单 broker | 集群（3 节点） |
| MySQL | 单实例 | 主从 + 自动故障转移 |
| 边缘代理 | 单床位单节点 | 可选双节点热备（关键床位） |

### 10.6.4 监控告警

生产环境建议接入：
- **Prometheus + Grafana**：监控服务指标（CPU/内存/连接数/QPS）
- **Loki / ELK**：日志集中收集与分析
- **AlertManager**：服务异常自动告警（邮件/钉钉/短信）
