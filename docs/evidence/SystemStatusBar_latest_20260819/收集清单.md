## 三、本次采集中发现并修复的缺陷

**心跳周期与前端过期阈值不匹配（已修复）**
- 现象：compose 默认 `TICK_SECONDS=15`，边缘节点每 10 个周期才发布一次心跳（150s/次），而前端 `SystemStatusBar.vue` 心跳过期阈值固定 45s —— 状态栏"节点心跳"芯片常态误报 0/3。
- 修复：`edge-agent/src/main.py` 主循环心跳发布条件 `cycle % 10` → `cycle % 2`（30s/次 < 45s 阈值），已 rebuild + 重建 3 个 edge 容器，MQTT 总线实测每节点约 30s 一条 health。
